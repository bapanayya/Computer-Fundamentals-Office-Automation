# Computer Fundamentals & Office Automation Master Portal

A dedicated, comprehensive, and interactive educational learning portal engineered for the **Department of Physics**, **S.V.A. Govt. Degree College, Srikalahasti**.

---

## 🌟 Key Features

1. **Bespoke Academic Design & Modern UX**:
   - Custom academic UI with Inter and JetBrains Mono typography.
   - Refined Dark and Light theme toggle with `localStorage` persistence.
   - Sticky top navigation bar with quick track-switcher pills and instant search (`Ctrl+K`).
   - Collapsible & resizable hierarchical curriculum sidebar with preset widths (Narrow, Default, Broad).
   - Reading progress bar and topic completion tracking.

2. **Complete Syllabus Coverage (61 In-Depth Chapters)**:
   - **Track 1: Hardware & Evolution (Unit 1)**: Positional number systems (Binary, Decimal, Octal, Hexadecimal), radix conversions, binary arithmetic, 1's and 2's complement, computer evolution from Abacus to ENIAC, Von Neumann CPU block diagram, five computer generations, and Unit 1 infographic activity guide with 10-point rubric.
   - **Track 2: Computer Organization & Networking (Unit 2)**: Input/Output peripheral devices (OCR, OMR, MICR, printers, plotters), storage types, memory hierarchy pyramid (Registers to Cloud), types of computers (Micro to Supercomputers, PARAM series), networking fundamentals, LAN/MAN/WAN, topologies (Star, Bus, Ring, Mesh), Internet vs WWW, IPv4 vs IPv6, DNS resolution, email protocols (SMTP, POP3, IMAP), and Unit 2 concept map rubric.
   - **Track 3: Word Processing & Presentation Design (Unit 3)**: MS Word and Google Docs interfaces, character & paragraph formatting, heading styles hierarchy, automated Table of Contents (TOC) generation, tables, SmartArt, Mail Merge automation, PowerPoint presentation principles (6x6 rule, contrast), Slide Master, multimedia integration (audio voiceover, video), animations vs transitions, Presenter View, keyboard shortcuts cheat sheet, and Unit 3 project proposal rubric.
   - **Track 4: Spreadsheet Engineering (Unit 4)**: Grid anatomy, relative vs absolute referencing (`A1` vs `$A$1`), math & statistical functions (`SUM`, `AVERAGE`, `COUNT`, `COUNTA`, `MIN`, `MAX`), string functions (`LEFT`, `RIGHT`, `MID`, `LEN`, `TRIM`, `CONCAT`, `TEXTJOIN`), sorting, AutoFilter, charting, logical decision functions (`IF`, `AND`, `OR`, `IFERROR`), classic lookups (`VLOOKUP`, `HLOOKUP`), modern lookups (`XLOOKUP`, `INDEX + MATCH`), and Unit 4 practical test rubric.
   - **Track 5: Data Modelling & Advanced Analytics (Unit 5)**: Advanced conditional formatting (rules, data bars, color scales, icon sets, row-highlight formulas), Data Validation (drop-downs, constraints, input messages, Stop error alerts), What-If Analysis (Goal Seek, Scenario Manager, 1 & 2-variable Data Tables), Pivot Tables, Pivot Charts, interactive Slicers & Timelines, dual-axis Combo Charts, in-cell Sparklines, executive dashboard design, productivity tips (Named Ranges, Freeze Panes, Split View), and Unit 5 dashboard rubric.
   - **Track 6: Complete Practical Lab Manual (All 14 Experiments)**: Full step-by-step procedures, hardware checklists, data tables, formula guides, expected outcomes, and viva voce Q&A for every prescribed lab:
     - *Exp 1:* PC Assembling and Disassembling Demonstration
     - *Exp 2:* Institutional Network Topology Mapping
     - *Exp 3:* Professional Resume Preparation in Word
     - *Exp 4:* Official 10-Day Leave Application Letter
     - *Exp 5:* Multimedia Presentation with Audio Voiceover & Video
     - *Exp 6:* College Class Time Table Grid Design
     - *Exp 7:* Employee Gross & Net Salary Payroll Calculator
     - *Exp 8:* Student Marks Sheet & Class Result Generation (20 students)
     - *Exp 9:* Automated Grade Evaluation using IF, AND, OR, IFERROR
     - *Exp 10:* Employee Database Search Engine (VLOOKUP, HLOOKUP, XLOOKUP, INDEX+MATCH)
     - *Exp 11:* Multi-Regional Sales Report with Pivot Tables, Charts & Slicers
     - *Exp 12:* Student Admission Data Entry Form with Drop-Downs & Validation Rules
     - *Exp 13:* Monthly Budget Planning using Goal Seek & Scenario Manager
     - *Exp 14:* Capstone Executive Performance Dashboard with Slicers & Sparklines

3. **Interactive In-Browser Learning Tools**:
   - **Live In-Browser Excel Formula Sandbox**: Edit numbers and strings in real time and evaluate real formulas (`SUM`, `AVERAGE`, `IF`, `COUNT`, `LEFT`, `RIGHT`, `MID`, `LEN`, `TRIM`, `CONCAT`, `TEXTJOIN`, `VLOOKUP`, `XLOOKUP`, `INDEX`, `MATCH`) with instant reactive recalculation.
   - **Multi-Radix Number System Converter**: Convert across Decimal, Binary, Octal, Hexadecimal, 1's Complement, and 2's Complement with step-by-step mathematical division proofs.
   - **Interactive Network Topology Simulator**: Real-time canvas demonstrating packet transmission across Star, Bus, Ring, and Mesh networks with simulated node/cable fault testing.
   - **CPU Architecture & Memory Flow Animator**: Structural visualization of Von Neumann subsystems and memory hierarchy latency tiers.

4. **"Test Your Understanding" Quizzes (183 Exercises)**:
   - Interactive multiple-choice exercises (3 per topic across all 61 topics).
   - Immediate feedback with explanatory pedagogical notes and "Show Solution" helpers.

5. **Official YouTube Channel Integration — The Competitive Edge**:
   - Integrated links and promotional banner for the college's official channel: [The Competitive Edge (@TheCompetitiveEdge-b4z)](https://www.youtube.com/@TheCompetitiveEdge-b4z).

You can upload this project directly to your new GitHub repository **`bapanayya/Computer-Fundamentals-Office-Automation`**:

1. **Initialize Git inside this folder**:
   ```powershell

   git init
   git add .
   git commit -m "Initial commit: Computer Fundamentals & Office Automation Master Portal"
   ```

2. **Link to your GitHub repository**:
   ```powershell
   git branch -M main
   git remote add origin https://github.com/bapanayya/Computer-Fundamentals-Office-Automation.git
   git push -u origin main
   ```

3. **Enable GitHub Pages for Free Live Hosting**:
   - Go to your repository on GitHub &rarr; **Settings** &rarr; **Pages**.
   - Under **Build and deployment** &rarr; **Branch**, select `main` / `/(root)` &rarr; Click **Save**.
   - Your site will be live at:
     ```
     https://bapanayya.github.io/Computer-Fundamentals-Office-Automation/
     ```
